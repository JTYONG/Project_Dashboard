Welcome

This is a working first-version demo of the MyHealthReport pipeline: profile intake → blood report entry → classification → red-flag check → risk stratification → domain analysis → targeted questions → prioritised, explained recommendations → final report.

It implements the Phase 1 scope from the framework (metabolic / cardiovascular domains) end to end, entirely in your browser — nothing is sent anywhere.
