# Project_Dashboard
## For Developers
### To access to working executable version. 
1. Clone this repository to your local device. 
    1. Go to your favourite folder, create a empty directory (example path to the empty directory: "C:\Users\Asus\Downloads\Testing").
    2. Open your terminal and paste the following code:
    >For Windows User (Paste at windows terminal): 
    ```bash
    git clone https://github.com/JTYONG/Project_Dashboard.git "C:\Users\Asus\Downloads\Testing"
    ```
    >For Linux (Assumed to be Ubuntu Distro, and have Git preinstalled) User (Paste at terminal):
    ```bash
    gh repo clone JTYONG/Project_Dashboard
    ```
2. Via explorer or terminal, enter the `JingTian - Phase i` directory.  
3. Enter the `Prototype1_Version2_FullStructure` directory
4. Run the `run.bat` file. This file will start up a terminal session to check dependencies and startup your default web browser to open the website. 


### Contribute to the Dashboard Project
Welcome to join our team! If you want to contribute to our project, you are adviced to follow the following contribution path:
1. Fork a version and develop with your favourite roadmap. 
2. Create a new branch and commit in that branch. 
3. Create your own file in the main branch (example`Dev1 - Developing`), and commit your changes into your personal file. 
> All developers are adviced to perform a pull request before continue working to avoid conflicts.
